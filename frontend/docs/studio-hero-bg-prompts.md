# 설교 준비실 히어로 배경 프롬프트 (Gemini용)

`/pastor/studio` 맨 위 **「설교 준비실」 히어로**(`pages/Pastor/PastorStudio.tsx` — 배지 · 제목 · 소개 2줄 · 6단계 칩)
뒤에 깔 배경. 라이트/다크 각 1장.

컨셉은 앱 전체와 같은 **코지-에픽 동화풍 + 같은 양 캐릭터**. 다만 이 화면은 담임목사님의 서재다 —
개그는 빼고 **진지하고 고요한 장면 + 한 군데만 작은 미소**(선교 히어로와 같은 톤).

장면: **늦은 시간 목양실 책상.** 펼쳐진 성경에서 옅은 빛이 피어오르고, 그 빛을 따라 종이 카드
(원어 낱말 쪽지 · 작은 지도 · 메모 · 접힌 원고)가 공중에서 **한 줄로 정리되며 원고 묶음으로 모인다** —
"말씀에서 재료를 모아 한 편의 설교로 엮는 과정"(= 6단계)을 장면 하나로. 멀리 창밖에 교회 강단/예배당 지붕.
목사님 양은 **뒷모습 혹은 옆모습, 화면 1/5 이하**. 표정 연기·말풍선 금지.

> 참조 이미지 2장 첨부: `public/images/title-bg/gospel_witness.webp`(캐릭터·화풍),
> `public/images/education/hero-light.webp`(빈 공간·라이트 톤 문법). "이 양 캐릭터와 완전히 같은 캐릭터로, 같은 화풍으로".
> **한 세션에서 라이트 → 다크 순으로** 이어서 뽑는다.

## 레이아웃 제약

- 히어로 실측: PC 약 1130×300(**≈3.8:1**), 모바일 약 420×360. 글자는 **왼쪽 정렬**, PC 텍스트 칼럼 ≈560px.
- 받는 비율: **16:9**(1536×864 근처). PC는 `cover; right center` → 가로 전체 · **세로 가운데 ≈50% 띠**만 보인다.
- → **장면 전체를 오른쪽 40% × 세로 가운데 띠** 안에. 왼쪽 55%는 **아무것도 없는 고요한 면**(벽/하늘 그라데이션).
- 모바일은 글자가 카드를 다 덮으므로 CSS에서 그림을 옅게(또는 숨김) 처리한다 — 그림 쪽에서 맞추지 않는다.
- 글자·숫자·로고·성경 본문 글씨 금지(종이엔 **글씨 대신 가는 선**). 테두리·비네트 금지. 워터마크 ✦ 자리(우하단)는 평평한 면으로.

## 적용 메모(붙일 때)

- 라이트 에셋을 쓰면 히어로 면이 **밝아지므로 글씨를 흰색 → `text-ink-strong`로** 바꿔야 한다(지금은 두 테마 모두 짙은 면 + 흰 글씨).
- 파일은 `src/assets/studio/hero-{light,dark}.webp`(public 아님 — SW 캐시가 옛 그림을 내준다), 한 장 60KB 이하.
